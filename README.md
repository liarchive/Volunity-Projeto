Plataforma web que conecta pessoas que querem ser voluntárias com instituições que precisam de ajuda. O objetivo é facilitar a busca por oportunidades de voluntariado local e simplificar o gerenciamento de vagas para as instituições. Projeto em desenvolvimento, criado como parte dos meus estudos em Engenharia de Software.

SOBRE O PROJETO: 

O Volunity tem duas frentes principais:

VOLUNTÁRIOS: encontram oportunidades de voluntariado perto de onde moram e se candidatam a ações que combinam com suas áreas de interesse (animais, educação, meio ambiente, saúde, entre outras).

INSTITUIÇÕES: publicam vagas de voluntariado e gerenciam os voluntários interessados.


TECNOLOGIAS UTILIZADAS: 

HTML5 — estrutura das páginas

CSS3 — estilização (sem frameworks)

JavaScript — interatividade (troca de abas, seleção de perfil, tags de interesse, redirecionamento entre páginas)

PHP (planejado) — back-end para validação de formulários

OBSERVAÇÃO: 
Este projeto ainda não possui um back-end. Os formulários de login e cadastro simulam o fluxo de autenticação (redirecionando para a página principal), mas não salvam ou validam dados de verdade. Futuramente, será adicionado um back-end feito em PHP, responsável por validar os dados dos formulários.
